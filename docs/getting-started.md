# Getting started

Walk through bringing up a fresh dev environment from zero. Plan ~45
minutes start to finish on a clean AWS account.

## Prerequisites

- AWS account you have admin in. Not your personal one — costs are
  ~$370/month if you leave it running.
- `terraform` 1.6+, `terragrunt` 0.66+, `kubectl` 1.30+, `helm` 3.15+,
  `aws` CLI v2.
- A Route53 hosted zone you control. The platform expects to mutate
  records on it for ExternalDNS and cert-manager.

## 1. Bootstrap the state backend

```bash
./scripts/bootstrap-backend.sh \
  terrascale-tfstate-<account-id> \
  terrascale-tflock \
  us-east-1
```

This creates the encrypted, versioned S3 bucket and DynamoDB lock table
the rest of the platform expects.

## 2. Wire your account id

Edit `terraform/live/account.hcl` and set `account_id` to your AWS
account number. The provider blocks generated by Terragrunt fail-fast if
you target the wrong account, so this is load-bearing.

## 3. Apply the dev environment

```bash
cd terraform/live/dev
terragrunt run-all apply
```

Order matters: network → eks → karpenter → ingress → argocd → observability
→ secrets. Terragrunt resolves the dependency graph from the `dependency`
blocks in each unit.

Expect ~25 minutes for the EKS control plane and ~10 minutes for everything
on top.

## 4. Bootstrap ArgoCD

Follow [runbooks/argocd-bootstrap.md](runbooks/argocd-bootstrap.md). After
the root app-of-apps lands, ArgoCD adopts every chart under
`kubernetes/platform/dev/`.

## 5. Update kubeconfig

```bash
./scripts/update-kubeconfig.sh dev
kubectl get applications -n argocd
```

You should see a row per directory under `kubernetes/platform/dev/`,
all converging on Synced/Healthy within ~5 minutes.

## 6. Hit the sample app

```bash
# Once cert-manager has issued the cert (watch with `kubectl get certificate -A -w`).
curl -sf https://sample.dev.example.com
# => Hello, DevOps!
```

## 7. Tear down

```bash
cd terraform/live/dev
terragrunt run-all destroy
```

This blows away the cluster but **not** the Loki S3 bucket
(`force_destroy = false`). Empty it manually if you want it gone.
