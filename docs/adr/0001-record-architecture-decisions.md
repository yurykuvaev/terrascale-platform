# 1. Record architecture decisions

Date: 2024-04-02

## Status

Accepted

## Decision

Significant architectural decisions get an ADR in `docs/adr/`, numbered
sequentially, Nygard format, immutable once accepted. Supersede via a new
ADR rather than editing.

## Why

Six months in, "why did we pick this?" loses fidelity. ADRs keep the
reasoning attached to the code.
